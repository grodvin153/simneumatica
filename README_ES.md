# Copia base del simulador neumático

Este proyecto parte del código oficial de `picuino/neumatic`, publicado como software libre bajo `GPLv3`.

Enlaces de referencia:

- Web original: `https://www.picuino.com/neumatic/index.html`
- Repositorio oficial: `https://github.com/picuino/neumatic`

Estructura útil del proyecto:

- `source/index.html`: fuente principal de la aplicación.
- `source/*.txt`: ejemplos que se cargan desde el menú.
- `docs/`: salida lista para publicar después del build.

Comandos:

- `npm install`
- `npm run build`

Notas para republicar:

- Conserva los avisos de autoría y la licencia `GPLv3`.
- Cambia metadatos como favicon, URL canónica y textos de marca cuando tengas tu nuevo dominio.
- La compilación ya copia los ejemplos `.txt` a `docs/` para que la versión publicada funcione completa.
